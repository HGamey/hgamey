结果清单与小报告在正在运行的中心直接登记，不用停机——和 agent 平时 pf-node results register/import 走的是同一个接口。登记是不可变的，重复同 ID 同内容不会再写。

schema 为 phonefarm/result@1，需有效 result_id 和非空标题（≤240 字符）。整条登记 ≤256 KiB；大原件请保留为命名来源。数值、单位和来源由服务端核验。

最多 1 MiB UTF-8 文本。选择文件不会上传整包；只保存这一份报告文本，它引用的图片、轨迹、视频或游戏资源不会自动复制，原统计不重算。

整条任务的导出包含作业、研究历史和附件。真正写入（apply）要备份并替换中心的三个数据库，必须先停掉接收方的中心才能做——一个任务和整个中心用的是同一段代码，这条不变。所以网页只做预演（dry-run）：上传导出 zip、核对计划，真正导入由下方给出的命令行在停机后手动执行。

最多 512 MiB；更大的导出包请直接用命令行预演与导入。上传后只做校验和计划，不写入任何数据，用完即删。
